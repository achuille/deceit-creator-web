# Deceit skin kits

[Open the tool](https://achuille.github.io/deceit-creator-web/)

Search a model, open its source preview, or download its Photoshop/Blender kit.
The artist ZIPs require access to the private Deceit Creator repository.

The public preview data is pinned independently from the website. Existing kit
releases remain unchanged. These are browser source previews; full native shader
and animation blending parity is not established.
